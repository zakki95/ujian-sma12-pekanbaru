# Aplikasi Ujian Online — SMA Negeri 12 Pekanbaru

Repositori ini berisi aplikasi ujian online untuk SMA Negeri 12 Pekanbaru,
ditujukan untuk 1.200 siswa serentak.

## Dokumentasi

Seluruh perencanaan, keputusan, dan status proyek didokumentasikan di folder `docs/`:

- `BLUEPRINT.md` — Gambaran besar produk dan arsitektur.
- `PROJECT_STATE.md` — Status terkini per tahap.
- `DECISIONS.md` — Keputusan yang sudah tetap dan yang belum diputuskan.
- `DATABASE_SCHEMA.md` — Rancangan skema database.
- `TASK_CHECKLIST.md` — Daftar tugas per tahap.
- `TESTING.md` — Strategi pengujian.
- `SECURITY.md` — Kebijakan keamanan.
- `DEPLOYMENT.md` — Rencana deployment.
- `HANDOFF.md` — Catatan serah terima konteks.

## Cara Memulai

Baca `docs/BLUEPRINT.md` dan `docs/PROJECT_STATE.md` terlebih dahulu.
Pekerjaan dilakukan per tahap sesuai `docs/TASK_CHECKLIST.md`.

## Catatan Penting

- Jangan menyimpan kata sandi, token, APP_KEY, atau rahasia lain di repositori.
- Jangan menjalankan migrasi sebelum skema disepakati.
- Jangan mengklaim fitur sudah selesai sebelum ada bukti pengujian.
